# Keyboard shortcuts

Press **?** in the app for this list on screen. Keys are the same with or without Caps Lock. Keys typed in a text box (metadata, name, labels, search) or in the import window never tag photos, including the Enter that confirms a box.

To get the keys back from a text box: press **Escape**, click anywhere outside the box, or close the view. Running a search also hands the keys to the results, so the arrows and number pad move through them straight away.

## Main viewer

### Moving around

| Key | Action |
|---|---|
| ← / → (or numpad 4 / 6) | Previous / next image (within the current pass) |
| Tab | Next unreviewed image |
| R / ⇥ Resume | The furthest image with a tag or rating: where you got to last time |
| K | The predicted keeper of this burst |
| Scroll wheel | Zoom in / out |
| Drag | Pan when zoomed |
| Z | 100 % zoom at the mouse (again: fit) |
| E | 100 % on the animal's eye (again: whole frame) |
| Escape | Reset zoom to fit |

### Tagging

| Key | Action |
|---|---|
| B or Enter | Best |
| D or Backspace | Delete (auto-advances unless Auto→ is off) |
| I, Space or + | ID (identify later) |
| 1 – 5 | Star rating |
| 0 | Clear rating |
| N | Accept the suggested species (whole burst, unless that option is off) |
| Ctrl + Z | Undo (tags, ratings, keywords, metadata; 50 steps) |

### Display tools

| Key | Action |
|---|---|
| F | Focus peaking (red edges) |
| H | Blown highlights from the RAW data (red: all channels, magenta: one or two) |
| L | Loupe (≥ 100 %, follows the mouse) |
| P | Focus point (yellow), detected animals (cyan) and eye (green) |

### Views

| Key / button | Action |
|---|---|
| G | Gallery (again or Escape: close) |
| V / ◎ Sightings | Sightings view |
| X | Add / remove the photo from the compare set |
| C | Compare view (2–4 photos) |
| ⚡ Clean Load | Lowest scorers first |
| ⊹ Bursts | Step through burst groups |
| 🔎 ID Review | Identify ID-tagged frames |
| 🔍 Search | AI search across your library folders |
| ? | Shortcut overlay |
| Q | Quit (asks first) |

## Gallery, Clean Load, bursts, search results

| Key | Action |
|---|---|
| Arrow keys, Page Up / Down, Home / End | Move the cursor |
| Number pad 4 / 6 / 8 / 2, 9 / 3, 7 / 1 | The same: left / right / up / down, page up / down, first / last |
| Enter, number pad Enter or double-click | Open the photo in the normal viewer |
| Shift + arrows / Shift + click | Select a range |
| Ctrl + click / Ctrl + A | Toggle one / select all shown |
| B, D, I, 1–5, 0 | Tag or rate the selection (or the photo under the cursor), as one undo step |
| Escape | Clear the selection, then close the view |

## Sightings view

All the gallery keys above, plus:

| Key | Action |
|---|---|
| Tab | Mark this sighting done, go to the next |
| ] / [ | Next / previous sighting without marking |
| N | Set the species for the whole sighting (one undo step) |
| R | Regroup (after more species suggestions have arrived) |
| V or Escape | Close |

## ID Review

| Key | Action |
|---|---|
| 1 – 5 | Pick that suggestion |
| Enter | Confirm |
| U | Unsure |
| X | Not identifiable |

## Species list Review

| Key | Action |
|---|---|
| 1 – 3 | Pick that guess (already in the list: keep the photo there, remove this copy) |
| Shift + 1 – 3 | Pick that guess and keep this photo instead |
| Enter | Confirm the name in the box |
| Shift + Enter | Confirm, and keep this photo instead of the one in the list |
| Del / X | Remove this photo from the list (a species seen elsewhere keeps its next photo) |
| Ctrl + Z | Undo the last change |
| ← → | Previous / next photo |
| ↑ ↓ | The burst's other frames |
| V / double-click | Open the original |
| Esc | Close |

## Buttons without keys

| Button | Action |
|---|---|
| Pass | Cycle: All → Survivors → Best → off |
| Auto→ | Auto-advance: off / after Delete / after Best and Delete |
| ⛶ | Full screen |
| ▶ Process | Copy Best, convert ID, recycle Delete |
| ✎ Rename (folder list) | Rename the folder (also on right-click) |
